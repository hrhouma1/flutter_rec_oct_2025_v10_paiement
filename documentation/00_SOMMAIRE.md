## Niveau requis

Cette documentation suppose que vous avez :
- Des bases en Flutter (widgets, state, navigation)
- Des notions de programmation asynchrone (Future, Stream)
- Une compréhension basique des bases de données
- Des notions de HTTP et d'APIs REST

## Durée d'apprentissage estimée

- Lecture complète : 4-6 heures
- Configuration pratique : 2-3 heures
- Exercices et expérimentation : 3-5 heures
- Total : 9-14 heures pour maîtriser le sujet

## Conventions

Dans cette documentation :
- Les commandes terminal sont préfixées par `$`
- Les chemins de fichiers sont entre guillemets : `lib/main.dart`
- Les concepts importants sont en **gras**
- Les extraits de code sont commentés en français
